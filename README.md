# Оплата через Т-Банк: SberPay · СБП · T-Pay · карта (пакет для Photogen)

Коротко для человека. Всю работу по переносу делает ИИ-агент по файлу **`AGENT.md`** — вам нужно дать ему этот репозиторий, настроить кабинет банка и принимать решения «катим / не катим».

## Что это даёт

* **Дешевле комиссия.** В среднем около **2,65 %** с платежа против примерно **3,87 %** у ЮKassa (по нашей структуре платежей; ваша цифра зависит от доли карт и СБП).
* **Конверсия такая же, как у ЮKassa.** Мы ожидали прирост около +12 % от «быстрых» кнопок — **это не подтвердилось**, не закладывайте его в расчёты. Выгода — в комиссии.
* **Запасной ЮKassa при сбое нет:** если Т-Банк не ответил в момент оформления, оплата не создаётся и покупатель видит ошибку — поэтому после включения нужен мониторинг (логи и число ошибок создания платежа). Вернуть всех на ЮKassa можно переключением флагов за минуту.
* **Можно включать постепенно:** сначала один аккаунт владельца → 10 % → 25 % → 50 % → 100 %.
* Видно, чем платят: тип способа (SberPay, СБП, T-Pay, карта, Mir Pay) записывается у каждого платежа.
* Возвраты (кнопка в инбоксе) идут через API банка.

## Что нужно сделать в кабинете Т-Бизнеса (интернет-эквайринг)

1. Взять **ключи терминала** (TerminalKey и Password) — отдельно **тестового** и **боевого**. Передавать агенту/серверу не в чате и не в репозитории, а в секреты сервера.
2. Включить **обе платёжные формы** терминала и способы оплаты: **карты, СБП, T-Pay, SberPay, Mir Pay**. Тип платежа — **одностадийный**.
3. Включить **HTTP-уведомления** терминала на адрес, который назовёт агент (вида `https://<your-domain>/api/v1/payments/tbank/notify`). Без уведомлений платёж всё равно зачтётся, но с задержкой до пары минут (агент ставит страховку — опрос статуса).
4. **Онлайн-кассу и передачу чеков не подключать**, если вы на НПД (чеки — из «Мой налог»). Если касса включена, платёж без чека банк отклонит.
5. Если в терминале включён список разрешённых IP — добавить IP вашего сервера.
6. Уточнить в договоре **тариф** (по нашему терминалу, 10.11.2026):
   * карты, T-Pay, SberPay, Alfa Pay — **3,19 %** (минимум 3,49 ₽ за платёж);
   * **СБП — 0,7 %**, минимальная сумма 10 ₽;
   * UnionPay — 3,49 %;
   * **1 ₽ за каждую неуспешную авторизацию** (отказ карты тоже стоит денег);
   * акционные ставки (например, 0,99 %) могут быть временными и не на все способы — спросите у менеджера, на что и до какой даты.

   Реальный выигрыш зависит от того, какая доля платежей идёт через СБП (самый дешёвый способ).

## Что попросить у агента

* «Прочитай `AGENT.md` и `GOTCHAS.md` и сначала напиши мне, чем ваш текущий Т-Банк отличается от того, что в ките, и какой вариант переноса выбираешь (A или B)».
* «Не включай ничего в проде, пока я не скажу. По умолчанию всё должно работать как раньше».
* «Сначала тестовый терминал на стенде, потом боевой на одном моём аккаунте, потом проценты».
* «Покажи тесты: подпись по примерам из документации, зачисление как у ЮKassa, при сбое Т-Банка оплата не создаётся и не уходит в ЮKassa».
* «Скажи, что ты не смог проверить сам» (нужны проверки на телефоне: открытие SberPay/СБП/T-Pay из Telegram и MAX, ввод карты внутри приложения).

## Что внутри репозитория

Структура папок = структура Photogen, чтобы файлы копировались «один в один». Подробная карта — `FILES.md`.

| Папка / файл | Что |
|---|---|
| `AGENT.md` | пошаговый чек-лист для агента: «скопируй файл X в Y, в файле Z замени функцию F на нашу» |
| `GOTCHAS.md` | грабли, на которые мы уже наступили (агент читает до кода) |
| `FILES.md` | карта: какие файлы копировать как есть, какие сливать, зачем |
| `app/…`, `scripts/`, `tests/` | серверный код: клиент банка, выбор провайдера, API оплаты Mini App, воркер, миграции-шаблоны, тесты |
| `<файл>.changes.md` | рядом с каждым файлом, который есть и у вас: какие функции наши, что переносить, чего у вас не хватает |
| `miniapp-ui-next/src/…` | наша шторка оплаты целиком (React/TS) + `miniapp-ui/src/platform/*` — готовые прослойки под ваш `miniapp-ui` |
| `telegram-bot/…`, `max-bot-core/…` | кнопки 2×2 в чате бота — необязательно, у нас **выключены**, стандартная форма Т-Банка работает не хуже |
| `env.example` | имена переменных окружения (без значений) |

**Важно:** это не «поставил и заработало». У вас уже есть своя интеграция Т-Банка (её заменяем нашей) и нет экрана оплаты в приложении; наши файлы, которые есть и у вас (`payments.py` и др.), лежат целиком, но агент **вносит правки по меткам**, а не перезаписывает ваши файлы. Ожидайте несколько итераций и вопросов от него.
